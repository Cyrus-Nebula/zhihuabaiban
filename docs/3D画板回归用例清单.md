# 3D 画板回归用例清单

> 独立自主 3D 画板（路线A 替代方案，基于本地 Three.js，不依赖大角几何 SDK / appId）。
> 每轮跑通后在「状态」列打勾；未通过或尚未实现留空。
> 命令协议与 `js/board3d.js` 的 `createBoard3DExecutor` 一一对应，改协议两边同步改。
> 无头逻辑回归见 `tests/board3d_regress.mjs`（不依赖 WebGL，沙箱内可直接跑：`node tests/board3d_regress.mjs`）。

## 已知限制 / 后续
- 沙箱无头环境无 WebGL，无法出真实渲染截图；渲染相关项（12/13）需在有 GPU 的浏览器目视确认。
- `line3d` 当前为「过两点的有限长线段 + 两端延长」近似，非无限直线解析。
- 多层 face 叠加时透明度混合顺序依赖渲染顺序，复杂重叠体可能有轻微 z-fighting（可用 `depthWrite` 调优，后续）。
- 无头回归（`tests/board3d_regress.mjs`）已覆盖：正方体(1)、四棱锥(2)、球体/圆柱/圆锥/圆/直线(3)、文字/标注/样式(4)、测量 distance/angle(5)，以及依赖缺失 / id 重复 / moves 往返等健壮性项。
