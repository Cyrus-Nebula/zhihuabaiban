## 已知限制 / 后续
- 沙箱无头环境无 WebGL，无法出真实渲染截图；渲染相关项（11/12）需在有 GPU 的浏览器目视确认。
- `line3d` 当前为「过两点的有限长线段 + 两端延长」近似，非无限直线解析。
- 多层 face 叠加时透明度混合顺序依赖渲染顺序，复杂重叠体可能有轻微 z-fighting（可用 `depthWrite` 调优，后续）。
