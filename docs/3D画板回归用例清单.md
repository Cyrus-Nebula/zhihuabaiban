# 3D 画板回归用例清单

> 路线B 自研立体画板：`board3d.html` + `js/board3d.js` + `libs/three/`（Three.js r160 本地 vendor）。
> 目的：把「3D 内核加载 / 基础图元 / 交互视角 / 标注与命令」的回归点固化下来，
> 每轮增量跑通打勾，防止 vendor 升级、importmap 改动或内核重构把已修好的能力打回原形。
> 本清单只管 3D；`docs/AI作图回归用例清单.md`（2D 作图主干）由并行的「AI 对标」任务维护，两边互不覆盖。
> 状态列：**✅ 已跑通 / ⬜ 待验证**（标 ⬜ 表示本沙箱尚无真实 WebGL 渲染环境做目视或截图确认，不代表功能缺失）。

| A2 | importmap 本地化 | `three` → `./libs/three/three.module.min.js`，`three/addons/` → `./libs/three/addons/`，无任何 CDN 键 | ✅ | 解析 `board3d.html` importmap JSON |
| A3 | 三个本地模块可达 | `three.module.min.js` / `OrbitControls.js` / `TransformControls.js` 均返回 200 | ✅ | 真实 `board3d.html` 断网加载时监听响应 |
| A4 | ESM 语法与依赖闭合 | 三个文件 `node --check` 通过；`board3d.js` + 两个 addon 的 import 全集都能被 importmap 解析到真实文件 | ✅ | 静态扫描 + Node 语法检查 |
| A5 | 版本一致性 | `THREE.REVISION === '160'`，与 vendor 前 CDN 版本一致，行为不变 | ✅ | 浏览器内读取 REVISION |

| A7 | 控制器可实例化 | `OrbitControls` / `TransformControls` 构造成功且关键方法存在 | ✅ | 浏览器内实例化并探测方法 |
| A8 | 硬约束回归 | `editor.html`、`js/editor.js` 的 `@dajiaoai/algeo-sdk` 与 `appId` 逻辑、`js/workbench.js` 均未被破坏 | ✅ | git blob sha 逐字节比对远程 main |
| A9 | WebGL 真实像素渲染 | 画布实际出图（draw calls > 0）、截图目视无损 | ⬜ | 本沙箱无头 Chromium 缺 SwiftShader，无法创建 WebGL 上下文；需有 GPU 环境补跑 |

> A 组备注：`board3d.html` 中 `@supabase/supabase-js` 的 CDN 脚本属于账号体系（登录墙 / 云同步），
> 断网时会失败，但**不影响 3D 内核加载**；本轮未纳入 vendor 范围，见 `libs/three/README.md`。
