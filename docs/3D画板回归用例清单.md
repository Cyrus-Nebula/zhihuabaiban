## 回退方式（新旧路径并存，直至替换条件完全满足）

1. **历史工程自动回退**：`content` 存在但不含自研 3D 命令数组 `cmds` 时，仍由 `editor.html` 打开，避免旧的大角 SDK 工程打不开。
2. **URL 开关**：工作台地址加 `?engine=sdk` 让所有 3D 文件走旧编辑器；`?engine=self` 强制自研（仅覆盖 localStorage 开关，不覆盖第 1 条历史数据保护）。
3. **localStorage 开关**：`localStorage.setItem('b3d.engine','sdk')` 可持久回退。
4. **卡片入口**：每个 3D 文件卡片都有「旧版打开」按钮，直接跳 `editor.html?id=...`。

> 2D 文件完全不受以上开关影响，始终走 `board.html`。

## 已知限制 / 后续
- 沙箱无头环境无 WebGL，无法出真实渲染截图；**真实 GPU 出图效果**仍需在有 GPU 的浏览器目视确认（交互逻辑已由替身渲染器冒烟覆盖）。
- `line3d` 已改进：原先是「过两点的有限长线段 + 两端各固定 4 单位」近似，现改为将无限直线裁剪到参考系球（`LINE_RADIUS = AXIS_LEN*2`，覆盖整个坐标架），端点随 a/b 拖拽与参考系边界实时更新，近似无限直线；两点重合（方向未定义）时安全降级（无头回归用例 6 覆盖）。
- ~~多层 face 叠加时透明度混合顺序依赖渲染顺序，可能有轻微 z-fighting~~ → **已处理（用例 24）**：半透明面 `depthWrite:false`，且顶点更新后重算包围体；极端密集重叠体的混合顺序仍依赖绘制顺序，如需像素级完美可后续引入 `renderOrder` / 深度剥离。
- 历史大角 SDK 格式的 3D 工程目前只能在旧编辑器中打开，尚未做格式迁移（如需迁移，先导出备份）。
- 无头回归（`tests/board3d_regress.mjs`）已覆盖：正方体(1)、四棱锥(2)、球体/圆柱/圆锥/圆/直线(3)、文字/标注/样式(4)、测量 distance/angle(5)、直线无限延伸裁剪(6)、工作面自适应(7)、三角扇顶点刷新(8)、remove3d 级联删除(9)、verify3d 三态自检断言(10)，以及依赖缺失 / id 重复 / moves 往返等健壮性项。
